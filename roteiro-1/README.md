# ProgWeb 2 — Roteiro Prático 01 (Parte 1)

Bootstrap 5 & Layout Responsivo Estático
CST em Sistemas para a Internet — IFSC Câmpus Garopaba

## Conteúdo

`index.html` reúne os Exemplos 1 a 5 do roteiro:

1. Grid responsivo e containers
2. Formulários e inputs estilizados
3. Cards, botões e alertas
4. Tabelas zebradas, hover e badges
5. Layout estático completo (cadastro `col-md-4` + tabela `col-md-8`)

Dependências (via CDN): Bootstrap 5 CSS, Bootstrap Icons e Bootstrap JS.

## Como executar

Abra a pasta no VS Code e o `index.html` no navegador (ou use a extensão Live Server).

## Conectar ao GitHub

1. Crie um repositório vazio no GitHub (sem README nem .gitignore), por exemplo `progweb2-roteiro01`.
2. No terminal do VS Code, dentro da pasta do projeto:

```bash
git init
git add .
git commit -m "Roteiro 01: layout estático com Bootstrap 5"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/progweb2-roteiro01.git
git push -u origin main
```

3. Nas próximas alterações:

```bash
git add .
git commit -m "descreva a alteração"
git push
```

Se for a primeira vez usando Git na máquina, configure antes:

```bash
git config --global user.name "Seu Nome"
git config --global user.email "seu-email@exemplo.com"
```
